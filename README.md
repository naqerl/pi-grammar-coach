# pi-grammar-coach

Pi extension: checks grammar of your prompts and shows one corrected sentence (casual or formal, tech tone) with a pencil icon.

## Install

```sh
pi install git:github.com/naqerl/pi-grammar-coach
```

Or copy `grammar-coach.ts` to `~/.pi/agent/extensions/`.

## Commands

- `/grammar casual` / `/grammar formal`
- `/grammar model <provider/id>` or `/grammar model default`
- `/grammar status`
